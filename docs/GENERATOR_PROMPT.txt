You are a senior full-stack engineer building Fantasy World Map Generator, a purely static browser app for GitHub Pages with no backend and no external API calls. Build vanilla JavaScript (JSDoc now, TypeScript later) with Vite. Enforce a four-layer architecture: (1) data layer = plain JSON WorldData with no methods; (2) generators = procedural algorithms that produce WorldData from a seed; (3) editors = tools that perform controlled mutations; (4) renderers = Canvas 2D (not SVG) that visualize WorldData without modifying cells. Implement geographically plausible generation inspired by Martin O'Leary (irregular mesh, depression fill, cities on rivers), Amit Patel (dual mesh, ocean-vs-lake flood, Whittaker biomes, moisture from fresh water), and Scott Turner (tectonic chains, rain shadow / wind). Pipeline: jittered hex dual mesh + Lloyd relaxation; plate tectonics with velocity so continents come from plates not noise blobs and mountains form convergent chains; simplex noise only as small detail; ocean flood from map border; Barnes priority-flood so every land cell drains downhill; rivers follow downslope and never climb ridges; lakes are inland basins; temperature from latitude and elevation; moisture from orographic rain and rain shadow; biomes from Whittaker lookup; settlements scored toward rivers/coasts and banned from ocean/ice peaks; realms via cost-distance from capitals. Editors: pan/zoom, raise/lower terrain brush, river carve that forces a monotonic downhill channel then recomputes hydrology, move settlement onto land only, rename settlement. Persistence: LocalStorage autosave plus JSON import/export of the entire WorldData document plus high-res PNG via offscreen canvas. Performance: thousands of polygons with spatial-hash hit testing. UI: distinctive cartographer desk (ink, brass, ember), style presets atlas/physical/political/parchment/night, inspector panel. Deliver working prototype, docs (architecture, algorithms, MVP, deployment), and node:test plausibility tests that rivers never climb and northern land is not tropical. License AGPL-3.0.
